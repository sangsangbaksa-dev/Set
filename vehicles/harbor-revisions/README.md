# Project Harbor revised vehicles

These are the revised game-ready vehicle assets and editable Blender sources. This directory is separate from the earlier vehicle assets in Set PR #2; once that earlier PR is merged, these represent the updated Project Harbor designs. The GLBs preserve the prior vehicle bounds, ground pivot, +Z forward direction, `vehicle_paint` material, and wheel pivot and roll hierarchy.

| --- | ---: | ---: |
| Pier Runner | 9,512 | 8,124 |
| Breakwater Utility | 8,816 | 8,480 |

The procedural build recipe is maintained in Project Harbor's `tools/blender/build_vehicles.py`.
