# Project Harbor vegetation

Original alder, coastal pine and cypress models, each with an editable Blender scene and matching GLB. All use a ground-level pivot and a height of one metre; scale uniformly to the desired tree height. Detailed and `_lod` exports are separate models, each with opaque Bark and Foliage surfaces and no textures.

| Tree | Detailed triangles | LOD triangles |
| --- | ---: | ---: |
| Alder | 972 | 120 |
| Pine | 1,128 | 100 |
| Cypress | 584 | 80 |

The corresponding procedural Blender build script is maintained in the Project Harbor game repository.
