# Project Harbor street furniture

Original slatted bench and compact planter, each with an editable Blender source and matching game GLB. Both have ground pivots and two opaque materials. The bench faces local +Z in glTF coordinates.

| Prop | Dimensions | Triangles |
| --- | --- | ---: |
| Bench | 1.8 m wide, 0.56 m deep, 0.93 m high | 228 |
| Planter | About 0.68 m wide and 0.98 m high | 188 |

The procedural Blender build script is maintained in the Project Harbor game repository.
